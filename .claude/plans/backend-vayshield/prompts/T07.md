<workflow>
1. `git switch -c task/backend-vayshield/T07` (đã ở branch đó thì bỏ qua); xác nhận bằng `git branch --show-current`.
2. Trong `backend/`: `uv sync` (nếu đã có pyproject).
3. Viết test trước cho từng edge case được giao; tên test hoặc docstring chứa mã EC (vd `test_ec_db15_rls_blocks_cross_tenant`, `S2-EC12`).
4. Code tối thiểu, sạch, type hints đầy đủ; tiền tệ ở biên dùng int đồng/Decimal; không log PII/OTP.
5. Chạy verify: `uv run pytest <thư mục test của task> -q`, `uv run ruff check <file của bạn>`, `uv run ruff format <file của bạn>`, `uv run mypy <package của bạn>`. Fail → sửa → chạy lại. Không bao giờ báo PASS khi chưa chạy.
6. `git add` từng file/thư mục thuộc owns (KHÔNG `git add -A` hay `git add .`), commit: `feat(backend): <tóm tắt> [T07]`. Có thể commit nhiều lần.
7. KHÔNG push, KHÔNG merge, KHÔNG deploy, KHÔNG gọi API mạng thật (Gemini/Push/SMS dùng fake).
</workflow>
