<workflow>
1. `git switch -c task/backend-vayshield/T11` (đã ở branch đó thì bỏ qua); xác nhận bằng `git branch --show-current`.

5. Chạy verify: `uv run pytest <thư mục test của task> -q`, `uv run ruff check <file của bạn>`, `uv run ruff format <file của bạn>`, `uv run mypy <package của bạn>`. Fail → sửa → chạy lại. Không bao giờ báo PASS khi chưa chạy.
6. `git add` từng file/thư mục thuộc owns (KHÔNG `git add -A` hay `git add .`), commit: `feat(backend): <tóm tắt> [T11]`. Có thể commit nhiều lần.
7. KHÔNG push, KHÔNG merge, KHÔNG deploy, KHÔNG gọi API mạng thật (Gemini/Push/SMS dùng fake).
</workflow>
